📖 Why does this happen?

The core problem

A neural net has shared weights. When you train on Task B, gradient descent moves every weight toward fitting B. But those same weights were tuned for Task A — so A's fit gets destroyed.

Key terms

Catastrophic forgetting — the dramatic loss of previously learned skills when training on new data. It's "catastrophic" because the accuracy doesn't decline gracefully — it crashes.

Task similarity — if Task B is close to Task A (like rain vs. sunny), forgetting is milder. If B is very different (snow), forgetting is severe. The model can't reuse the same weight configuration.

The self-driving connection

Imagine your autonomous car was trained on sunny California roads. Winter arrives. You fine-tune on snowy data. Now the car handles snow — but it's dangerous on dry roads. That's catastrophic forgetting in production. Case 06 shows how to fix it.

🎮 Try this Train on Snow (very different from sunny). Notice nearly all weights turn red — there's no safe zone. Now reset and train on Rain (similar to sunny). Fewer weights drift, and the ones that do drift less. That's why similar tasks cause less forgetting.

3 · The Forgetting Curve

👁 What you're seeing A live plot of both accuracies over training steps. Green line = Task A accuracy (drops as you train on B). Colored line = Task B accuracy (rises as training proceeds). The crossing point marks when the model knows B better than A — the old skill is gone.
🎮 Try this Watch for the crossing point. With Snow, it happens fast (~30 steps). With Rain, it takes longer or the lines stay close together. Try a very low learning rate (drag slider left): forgetting is slower, but so is learning B. There's no free lunch.
