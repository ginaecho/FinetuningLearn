📖 Why does training on B destroy performance on A?

What am I looking at?

This is a real trained neural network (a small MLP) plotted in function space.

  • Green dots — the data for Task A: y = sin(x). The model was pre-trained to fit these.
  • Blue dots — the data for Task B: y = sin(x + 1.2). This is the "new information" we now train on.
  • The curve — what the model predicts for any input x. It starts fitting the green dots.
  • Residual lines — the vertical distance from each green dot to the curve. Longer = worse forgetting.

What does the slider show?

It steps through training on Task B only. At each step the optimizer sees only blue dots and updates weights to reduce the blue error.

  • Step 0 — curve hugs the green dots. Blue error is high.
  • Step 400 — curve is torn between green and blue. Both tasks are mediocre.
  • Step 800 — curve hugs the blue dots. Green error is huge. Forgetting is complete.

The mechanism: weights and biases

The model has no "memory slot" for Task A. It only has weights and biases that define a function. When B-training changes those numbers to fit the blue pattern, the old green pattern is overwritten. There is nowhere else to store it.

Key insight

Forgetting is not mysterious — it is the inevitable side effect of changing a function to fit new data. Unless you add a mechanism to preserve the old fit, the optimizer will overwrite it.

📖 Why does task similarity matter?

The loss landscape picture

Imagine the model's parameters as a point in a high-dimensional space. Each task has a "basin" — a region where parameters produce good predictions for that task.

  • Similar tasks — their basins overlap. Moving toward the new optimum barely hurts the old one.
  • Different tasks — their basins are far apart. Moving toward the new optimum means leaving the old basin entirely → severe forgetting.

Real-world implication

A self-driving model trained on sunny urban roads and then fine-tuned on rainy urban roads (similar task) will forget less than one fine-tuned on snowy mountain passes (very different task).

This is why continual learning is hardest when new data is distributionally different, not just more of the same.

📖 What does weight drift tell us?

From function space to parameter space

Panels 1–2 showed the symptom: predictions on old data got worse. This panel shows the cause: individual weights in the first layer are being rewritten.

What is the heatmap?

Each cell is one weight W[i,j] connecting input feature j to hidden neuron i. The color encodes the weight's value:

  • Red = strongly excitatory (positive, large magnitude)
  • Blue = strongly inhibitory (negative, large magnitude)
  • Black = near zero (no effect)

What is total drift?

The L2 norm ||W_now − W_initial||₂ — a single number summarizing how far the entire weight matrix has moved. Naive fine-tuning produces large drift. Freezing produces zero drift.

Why the first layer?

The first layer is where raw input features are transformed. If these weights change, the meaning of every downstream neuron changes too — the entire representation is remapped. That's why forgetting in early layers is especially damaging.
